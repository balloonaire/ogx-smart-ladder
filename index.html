Session settings

Court order is highest to lowest. Winners ascend one court; losers descend one court. Top-court winners defend for at most 2 consecutive rounds, then descend directly to the lowest-ranked court and mix with new partners.

Use the arrows to move any physical court number to TOP or lower ranks. The order is saved automatically. Reordering is disabled while matches are live.

Rules apply to new and ongoing matches. Score completion requires manual confirmation. A match is finished when the target and margin are reached, or the optional cap is reached.

Connect 3 or more devices — one shared session

Requires a configured Firebase Realtime Database. Enter the same database URL and session code on every device. Use Host / editor on one device and Live viewer on the others. A session code alone is not an access-control mechanism; configure Firebase authentication and database rules before using real player data.

Offline — local browser only

The host creates or joins a shared session. Viewers refresh automatically every 3 seconds. Only one host should edit at a time; this is not a multi-editor conflict-resolution system. Do not share authentication tokens.

Players & waiting queue

Rest removes a waiting player from match selection until resumed. Sub lower prioritizes an eligible waiting player for the next match on the lowest court; live matches are never interrupted.
